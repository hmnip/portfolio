TL;DR

BEAR-DEN is a self-driving lab for polymer research. It runs experiments without an operator, and each instrument is exposed through its own SiLA 2 server.

I developed the lab's orchestrator, which turns researcher requests into queued jobs, and I wrote the SiLA 2 server for the UV curing station.

I built ACUCS, a CNC-guided UV curing system that raised throughput about 12x, and an end effector that reached 100% success over a 50-transfer test.

Problem and constraints

A self-driving lab needs every instrument to accept jobs and report results with no one at the bench. BEAR-DEN's instruments come from different vendors.

  • Mixed hardware. A UFactory Lite6 6-DOF arm on a Vention linear rail, an Omnicure S1500 UV source, GRBL CNC gantries, a heater-shaker, and an Opentrons liquid handler all had to run as one system.
  • Manual transfers. 96-well plates were moved between instruments by hand.
  • Traceability. Every run had to be traceable after the fact.
  • Failure detection. With no operator present, a failed plate transfer had to be caught by the system itself.
  • Fit. Third-party instruments had to mount onto standardized gantries.

What I built

Sub-project

ACUCS: Automated Low-Cost CNC-Guided UV Curing System

ACUCS is my flagship sub-project. I assembled 3 CNC gantries and wrote the G-code motion control. It integrated 3 systems into one automated process and raised throughput about 12x.

Mechanical

  • CNC gantries. I assembled the 3 CNC gantries for ACUCS.
  • End effector. I designed a custom end effector for plate transfers. It reached a 100% success rate over a 50-transfer test.
  • Instrument mounts. I designed mounts in SolidWorks and 3D-printed them as rapid prototypes, so third-party instruments fit onto standardized gantries.

Electronics & Embedded

  • Distributed control. I integrated and controlled instruments through Raspberry Pi controllers. Python on a central PC directs each Pi over TCP/IP, so equipment from different vendors runs as one system.
  • Motion control. I wrote G-code motion control for the GRBL gantries in ACUCS.
  • Closed-loop transfers. I integrated an end-of-arm camera that validates each plate and stops the arm when a transfer fails.

Controls & Software

  • Orchestrator. I developed the lab's orchestrator. Researcher requests become jobs in a MySQL task queue, and the orchestrator dispatches them to the instrument servers. Results are logged append-only, so every run can be traced.
  • Request parser. I wrote the parser that turns researcher requests into jobs.
  • UV curing server. I wrote the SiLA 2 server for the UV curing station, including error handling and task polling.
  • Arm and rail. I wrote Python control scripts that coordinate the arm and rail to automate 96-well plate transfers that used to be done by hand.

Current work: MAP Hub

Since October 2026 I've been integrating a homogenizer and a fume-hood spray coater into a nine-instrument expansion served by a Universal Robots arm.

I'm building a digital twin of the arm and rail. I test planned motions in MuJoCo and check collisions in NVIDIA Isaac Sim before anything runs on hardware.
